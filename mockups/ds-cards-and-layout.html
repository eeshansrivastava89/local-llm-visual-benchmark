Design Notes for Full Page Layout

  • Toolbar: Single row. Kind tabs + view tabs on the left. Filters + search + refresh on the right. No wrapping at default widths. Clean separation.
  • Cloud toggle: Moved to the summary bar, right-aligned. It filters the results, so it belongs near the count/summary, not in the control bar.
  • Summary bar: Compact single line: title + count badge + summary text on the left. Cloud toggle on the right. Much cleaner than current multi-line summary.
  • Gallery: 4-column grid with 1.25rem gap. Cards lift + glow on hover. Video ring is always visible so users immediately know "click to watch."
  • Card body: Title + meta pills + footer. That's 3 lines vs current 5. Preview is 16:10 (~55% of card height) vs current 16:8.7 (~35%).
  • Data science: Same card structure but preview is a chart thumbnail with score badge floating over it. No video ring since DS outputs are static.
  • Theme: This mockup uses a cinematic dark theme for impact, but all designs can be adapted to the current light/dark theme system.
