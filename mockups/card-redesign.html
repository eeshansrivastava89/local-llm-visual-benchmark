Design Notes & Rationale

  • Video discovery: All three options add a visible video indicator. Option A uses a top-right play ring + center play overlay on hover. Option B uses a pulsing "VIDEO" badge. Option C uses a subtle corner play icon.
  • Preview dominance: Current preview is 16:8.7 (~35% of card). Option A is 16:10 (~55%), Option B is 16:9 (~50%), Option C is 4:3 (~75%).
  • Text density: Current has 5 text rows. Option A consolidates to title + 1 meta row + footer. Option B has title + tags. Option C hides metadata until hover.
  • Motion on hover: All options scale the preview image slightly and add visual feedback (glow, lift, overlay) to invite clicking.
  • Accessibility: All video indicators are visible without hover. Play overlay in Option A appears on hover as progressive enhancement.
  • Implementation note: The "video ring" badge in Option A can be conditionally rendered when run.assets?.videoMp4 exists. The play overlay can trigger the same lightbox the detail modal uses.
  • Recommendation: Option A (Cinematic) balances visual impact with information density. It gives the preview room to breathe, clearly signals "this is a video," and keeps essential metadata visible without clutter.
