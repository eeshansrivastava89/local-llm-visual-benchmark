Design Notes

  • Chart thumbnail: Uses a warm neutral gradient background + a white card with fake bars. Works in both light and dark themes. Real implementation would render the actual chart PNG.
  • Score badge: Floats bottom-right of the chart, color-coded by quality (great/good/ok/low). Semi-transparent background with backdrop blur so it never obscures the chart.
  • Card body:> Same 3-line structure as visual cards: title + meta pills + footer. No redundant status pill since the score badge already communicates quality.
  • Empty state: Shows a warning icon + "No output" text inside the chart area instead of a generic placeholder.
  • Prepared state: Spinner inside the chart area + "Analysis in progress" label. Communicates activity without needing a separate overlay.
  • Color coding: Green bars for great scores, orange for ok, red for low. This gives an "at a glance" quality signal before the user even reads the number.
