# Product

## Register

product

## Users

Local AI builders who run visual prompts through LM Studio, OpenCode, Pi, or other local tools and want a clear way to inspect, compare, and share the resulting HTML artifacts.

## Product Purpose

Local LLM Visual Benchmark is a local-first visual run viewer. It organizes saved benchmark outputs, teaches the folder convention, generates paste-ready tool prompts, and makes side-by-side review of model attempts pleasant without owning model execution.

## Brand Personality

Precise, calm, craft-aware. The product should feel like a focused lab bench for visual artifacts, not an orchestration dashboard or a marketing site.

## Anti-references

Avoid runner dashboards, queue monitors, leaderboard products, decorative AI gradients, heavy SaaS chrome, and interfaces that hide file paths or output conventions from the user.

## Design Principles

- Viewing is the product: prioritize artifact browsing, comparison, and inspection.
- Make the convention visible: show exact folders, expected files, and copyable prompts.
- Stay local and passive: discover LM Studio and files, but do not mutate LM Studio or run models.
- Teach through workflow: setup and run guidance should sit beside the task.
- Prefer simple primitives: custom Astro components and small scripts over broad UI frameworks.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-reachable controls, visible focus states, reduced-motion-safe transitions, and clear empty states for users learning the folder convention.
